# 🌍 CodeAlpha - Language Translation Tool

## 📌 Project Overview
An AI-powered Language Translation Tool that translates text from one language to another using Google Translate API.
Built as Task 1 of CodeAlpha Artificial Intelligence Internship.

## ✨ Features
- Translate text to 10+ languages (Telugu, Hindi, Tamil, Spanish, French, German, Japanese, etc.)
- Simple & Clean User Interface using Streamlit
- Source & Target language selection
- Instant translation with copy option
- Error handling for empty input

## 🛠️ Technologies Used
- Python
- Streamlit
- deep-translator (Google Translate API)

## 🚀 How to Run
1. Clone this repo
2. Install requirements: `pip install -r requirements.txt`
3. Run app: `streamlit run app.py`
